# v0.1.0 - Awesome CodeDesign

## Positioning

Awesome CodeDesign is a Supersynergy-curated map of the 500 most valuable visualization tools for code-design workflows: charts, diagrams, maps, graph/network views, 3D/WebGL/WebGPU, UI motion, video-as-code, creative coding, BI dashboards, and icon systems.

## What Ships

- Premium README with category map and local-first shortlist.
- Full 500-tool awesome list in `docs/awesome-list.md`.
- Static searchable gallery in `docs/gallery.html`.
- 500 generated SVG thumbnails in `docs/assets/examples/thumbs/`.
- Clean social preview image in `docs/assets/social-preview.png`.
- Data in `data/tools.json` and `data/tools.csv`.
