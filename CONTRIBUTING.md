# Contributing

This is a curated awesome list, not a dump. Additions should pass at least one of these tests:

- Solves a visual problem better than a current entry.
- Has strong source activity, clear examples, and a usable license.
- Adds a missing category or platform.
- Is locally useful for codedesigner, universalui, or Supersynergy build workflows.

## Entry Checklist

- Full GitHub URL: `https://github.com/<owner>/<repo>`.
- Official URL when available.
- License checked.
- Short capability note, not marketing copy.
- Category assigned.
- Example image or demo link included when possible.

Run `just check` before opening a PR.
